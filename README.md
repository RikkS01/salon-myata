# Сайт салона красоты «Мята»

Учебный проект производственной (эксплуатационной) практики, МУ им. С.Ю. Витте,
направление 38.03.05 «Бизнес-информатика». Автор – Яцко Сорин.
Салон, адрес и персонал вымышлены.

Сайт написан на **PHP 8.1+ и MySQL/MariaDB без CMS и фреймворков** и рассчитан на
локальный сервер **XAMPP** (Apache + MariaDB + PHP) и обычный PHP-хостинг.

## Возможности

* 10 разделов: главная, о салоне, услуги, мастера, цены, акции, новости, блог, контакты, онлайн-запись;
  в каждом разделе-ленте не менее 5 статей;
* версия для слабовидящих (ГОСТ Р 52872-2019): 3 размера шрифта, 4 цветовые схемы,
  отключение изображений, увеличенный интервал;
* карта сайта (`sitemap.php`, `sitemap.xml.php`) и собственная страница 404;
* баннеры на главной, поиск по сайту, лента новостей, контакты и обмен сообщениями
  (форма обратной связи и переписка в личном кабинете);
* регистрация и вход, роли: администратор сайта, администратор салона, клиент;
* панель управления: контент (CRUD + загрузка изображений), записи, сообщения, баннеры, пользователи;
* защита: хеширование паролей, подготовленные SQL-запросы, CSRF-токены, экранирование вывода,
  ограничение попыток входа, запрет выполнения скриптов в папке загрузок.

## Запуск в XAMPP

1. Установить XAMPP (https://www.apachefriends.org), запустить модули **Apache** и **MySQL**.
2. Скопировать папку `salon-myata` в `C:\xampp\htdocs\`.
3. Открыть http://localhost/phpmyadmin → «Создать БД» `salon_myata` (сравнение `utf8mb4_unicode_ci`)
   → вкладка «Импорт» → файл `database/salon_myata.sql`.
4. Открыть http://localhost/salon-myata/

Настройки подключения – в `config.php` (по умолчанию для XAMPP: `root` без пароля).

## Размещение на бесплатном хостинге

1. Создать сайт на хостинге с PHP 8.1+ и MySQL (например, InfinityFree).
2. Загрузить содержимое папки в `htdocs` через файловый менеджер или FTP.
3. В панели хостинга создать базу MySQL и импортировать `database/salon_myata.sql` через phpMyAdmin.
4. Скопировать `config.local.example.php` в `config.local.php` и указать данные базы.
5. В `.htaccess` заменить `ErrorDocument 404 /salon-myata/404.php` на `ErrorDocument 404 /404.php`.
